# Sakshi Agarwal — Portfolio

## How to use
1. Double-click `index.html` to open it in any browser. It works right now, as-is.
2. To swap in your own logo/photo files, drop them into `assets/logos/` and `assets/photos/`
   using the exact filenames listed in the README.txt inside each folder.
3. Refresh the page — no code editing required.

## Structure
```
index.html              ← the whole site (single file, self-contained)
assets/
  logos/                ← drop company logo images here
    README.txt          ← exact filenames needed
  photos/                ← drop your photos here
    README.txt          ← exact filenames needed
```

## Notes
- If a logo/photo file is missing, the site automatically shows a clean
  colored-initial badge (logos) or falls back to the original LinkedIn image
  (photos) — so it never looks broken, with or without the assets folder.
- Built from your LinkedIn profile (via Apify) and your resume PDF.
